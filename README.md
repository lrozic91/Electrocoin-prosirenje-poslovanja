# Electrocoin, savjeti za proširenje poslovanja

Statična web stranica (HTML/CSS/JS, bez build koraka) s prijedlozima proširenja poslovanja Electrocoina. Nastavak stranice [Electrocoin case study](https://electrocoin-case-study.mojaradnadomena.com/).

## Objava na Cloudflare Pages

1. Cloudflare → Workers & Pages → Create → Pages → Connect to Git → odaberi ovaj repozitorij.
2. Framework preset: **None**, build command: prazno, build output directory: `/`.
3. Custom domain: `electrocoin-prosirenje-poslovanja.mojaradnadomena.com`.
4. Svaki push na `main` automatski objavljuje novu verziju; svaka grana dobiva vlastiti pregled.

## Lokalni pregled

Otvori `index.html` u pregledniku.
